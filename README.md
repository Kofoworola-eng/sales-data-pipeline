# sales-data-pipeline
An end-to-end sales data cleaning pipeline, built to demonstrate real-world Git workflow (branching, PRs, conflict resolution, tagging)
**Status:** Actively maintained | Last updated August 2026 🚧

## Getting Started

1. Clone this repository
2. Install dependencies: `pip install pandas`
3. Run the cleaning script: `python scripts/clean_sales_data.py`
4. Find the cleaned output at `data/cleaned_sales_data.csv`

## Known Issues
This project currently has no error handling and may crash on malformed input.
